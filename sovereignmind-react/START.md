## 🔧 Troubleshooting

### Backend won't start
```bash
# Make sure port 5000 is free
npx kill-port 5000
npm run server
```

### Frontend won't start
```bash
# Make sure port 3000 is free
npx kill-port 3000
npm run dev
```

### API not working
- Check `.env` file has your API key
- Check backend terminal for errors
- Make sure backend is running
