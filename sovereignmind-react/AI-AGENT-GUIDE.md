# 🤖 AI Agent System - User Guide

## 🎯 What is an AI Agent?

Your SovereignMind is now a **true AI Agent** - not just a chatbot! It can:

- 🧠 **Think and Decide** - Chooses which tool to use
- 🛠️ **Take Actions** - Executes tasks using tools
- 💬 **Converse** - Uses Gemini AI when no tool is needed
- 📊 **Remember Context** - Maintains conversation state

---

## 🛠️ Available Agent Tools

### 1. **Wikipedia Search** 🔍
**Command:** `search [topic]` or `look up [topic]`

**Examples:**
- "search photosynthesis"
- "look up Albert Einstein"
- "find information about quantum physics"

**What it does:** Searches Wikipedia and returns a summary

---

### 2. **Calculator** 🔢
**Command:** `calculate [expression]` or just type math

**Examples:**
- "calculate 15 * 12 + 30"
- "solve 2^8"
- "what is 156 / 12"

**What it does:** Performs mathematical calculations

---

### 3. **Clock** ⏰
**Command:** `what time is it` or `what's the date`

**Examples:**
- "what time is it"
- "what's today's date"
- "current time"

**What it does:** Returns current date and time

---

### 4. **Quiz Generator** 📝
**Command:** `quiz me` or `test me`

**Examples:**
- "quiz me on mathematics"
- "test me on science"
- "give me a practice question"

**What it does:** Generates subject-specific quiz questions

---

### 5. **Note Saver** 💾
**Command:** `save note [content]` or `remember this`

**Examples:**
- "save note: Pythagorean theorem is a² + b² = c²"
- "remember this: photosynthesis converts light to energy"

**What it does:** Saves important information for later

---

### 6. **Study Planner** 📚
**Command:** `create study plan` or `learning plan`

**Examples:**
- "create study plan for mathematics"
- "make me a learning plan"
- "how should I study this subject"

**What it does:** Generates a structured 7-day study plan

---

## 🎨 How to Use

### **Method 1: Direct Commands**
Type the command directly:
```
User: search photosynthesis
Agent: 🛠️ Tool Used: Wikipedia Search
       Result: [Wikipedia summary]
```

### **Method 2: Natural Language**
Ask naturally, the agent will decide:
```
User: Can you look up information about black holes?
Agent: 🛠️ Tool Used: Wikipedia Search
       Result: [Wikipedia summary]
```

### **Method 3: Conversation**
For general questions, it uses Gemini AI:
```
User: Explain how photosynthesis works
Agent: 💬 Using: Gemini AI
       [Detailed AI explanation]
```
